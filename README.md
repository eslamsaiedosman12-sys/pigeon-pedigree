# سلالة الحمام – Pigeon Pedigree

## الرفع على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub (مثلاً `pigeon-pedigree`) وارفع كل محتويات هذا المجلد في الجذر (index.html في المستوى الأول).
2. من **Settings ← Pages**: اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)` واضغط Save.
3. بعد دقيقة يفتح الموقع على `https://USERNAME.github.io/pigeon-pedigree/`.
4. من الهاتف (Chrome): القائمة ← «إضافة إلى الشاشة الرئيسية» لتثبيته كتطبيق.

## مهم: البيانات والنسخ الاحتياطي
البيانات تُخزَّن في IndexedDB داخل متصفح كل جهاز، ولا تُرفع إلى GitHub أبداً. لنقل البيانات أو حمايتها:
**النسخ الاحتياطي ← تنزيل نسخة** ثم **استرجاع** على الجهاز الآخر. خذ نسخة بانتظام، فمسح بيانات المتصفح يحذف كل شيء.

## التشغيل محلياً
`python3 -m http.server 8080` ثم افتح http://localhost:8080
